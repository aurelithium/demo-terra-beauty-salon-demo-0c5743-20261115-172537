# Терра · салон — демонстрационный сайт

Статический адаптивный демо-лендинг салона красоты в стилистике warm editorial luxury. Весь контент (мастера, цены, отзывы, адрес, телефон) — **демонстрационные заглушки**, которые помечены плашками «демо»/«пример»/«placeholder» и должны быть заменены на реальные данные клиента до публикации.

## Структура проекта

```
/ (корень)
├── index.html   — разметка страницы (семантический HTML5, ARIA)
├── styles.css   — дизайн-система и все адаптивные стили
├── script.js    — вся интерактивность на чистом vanilla JS (этот файл)
└── README.md    — этот файл
```

Подключения в HTML строго локальные: `./styles.css` и `./script.js`. Внешних скриптов, iframe, аналитики, fetch и inline-обработчиков (`onclick=` и т.п.) нет.

## Запуск

1. Скачайте папку с файлами целиком (не переименовывая).
2. Откройте `index.html` в современном браузере — двойным кликом по файлу.
3. Для корректной работы шрифтов и локальной проверки через сервер (необязательно):

```
python3 -m http.server 8080
# затем http://localhost:8080
```

Сайт не требует сборки, npm-зависимостей или бэкенда.

## Интерактивность (script.js)

Скрипт полностью построен на нативных API, без библиотек:

- **Sticky-хедер.** При скролле страницы к шапке добавляется класс `is-scrolled` (уплотнение и граница).
- **Мобильное меню.** Кнопка-гамбургер с `aria-expanded` и точкой контроля `aria-controls="mobile-menu"`; открытие/закрытие меняет подпись для скринридеров, блокирует скролл `body`, закрывается по Esc, по клику на любую ссылку и при переходе на десктопные ширины. Фокус после открытия переходит к первой ссылке меню.
- **Активный пункт навигации.** `IntersectionObserver` подсвечивает ссылку в `.nav-list`, соответствующую видимой секции.
- **Reveal-анимации.** Секции и карточки мягко появляются (fade + подъём) один раз при попадании в вьюпорт. Полностью отключены при `prefers-reduced-motion: reduce`.
- **Счётчики цифр.** Значения в блоке «О салоне» (`data-count`) анимируются при появлении; при reduced-motion — сразу показывают финальное значение.
- **FAQ-аккордеон** на `<details>/<summary>`: реализовано поведение «открыт только один пункт». Работает с клавиатуры по умолчанию.
- **Плавный скролл к якорям.** Учитывает высоту хедера, переносит фокус на целевую секцию (`tabindex="-1"`) для доступности, обновляет URL через `history.replaceState`. При reduced-motion — мгновенный переход.
- **Демо-форма записи.**
  - Поля: имя, телефон, услуга, дата.
  - Валидация: имя — минимум 2 символа; телефон — минимум 10 цифр; услуга — обязательный выбор; дата — обязательна и не в прошлом (у `input[type=date]` выставлен `min` по сегодняшнему дню).
  - Проверка выполняется **на blur** и при отправке; ошибки выводятся под полем через `role="alert"` и `aria-invalid`.
  - При успешной валидации кнопка временно переходит в состояние «Обрабатываем…», затем показывается честное демо-сообщение: данные не отправляются. Форма сбрасывается.
- **Выбор мастера.** Клик по кнопке «Записаться к мастеру» подставляет имя мастера в пояснение к форме и скроллит к блоку записи.
- **Год в футере.** Если в разметке присутствует элемент с `data-year`, туда подставляется текущий год.

## Доступность

- Семантические лендмарки (`header`, `nav`, `main`, `section`, `footer`), `aria-labelledby` у секций.
- Skip-link в начале страницы для быстрого перехода к контенту.
- `:focus-visible` с заметным контуром акцентного цвета.
- Все интерактивные элементы достижимы с клавиатуры.
- Учитывается `prefers-reduced-motion`: анимации и плавный скролл отключаются.
- Минимальные тач-таргеты у кнопок — 44 px и выше.

## Демонстрационные ограничения

- **Нет реальной отправки данных.** Форма записи и кнопки мастеров не обращаются к серверу, не используют fetch, не сохраняют персональные данные. Сообщение о демо-режиме выводится явно (`role="status"`).
- **Нет оплаты, авторизации, мессенджеров и карт.** Телефонные ссылки `tel:+70000000000` — заглушки.
- **Все фото — плейсхолдеры.** Подписаны «placeholder», не выдаются за реальные работы салона.
- **Имена мастеров («Мастер А/Б/В»), цены, отзывы, адрес, часы и телефон — вымышленные заглушки**, помеченные плашками «демо»/«пример». Перед публикацией их нужно заменить на согласованный реальный контент.
- **FAQ-ответы** — черновые заглушки, требующие утверждения клиентом.
- Страница помечена `robots: noindex, nofollow` и не индексируется.

## Браузеры

Ориентировано на актуальные версии Chrome, Edge, Firefox, Safari (включая iOS Safari и Android Chrome) — используется только то, что поддерживается этими браузерами без полифилов: `IntersectionObserver`, `matchMedia`, `history.replaceState`, `<details>/<summary>`, CSS-переменные и `clamp()`.
